## HPB対策キーワード辞書（契約に効くワード）

- **お悩み・目的ワード**：ニキビケア / 毛穴ケア（毛穴詰まり・黒ずみ・引き締め）/ いちご鼻 / 肌のざらつき / 肌質改善 / 肌管理 / ポテンツァ（比較検討）
- **手法・状態ワード**：ハーブピーリング / 剥離あり・剥離なし / ダウンタイムなし / 当日メイクOK / 水光肌 / 陶器肌 / 白玉肌
- **信頼の数値化ワード**：満足度 / 口コミ★4.9 / リピート率〇% / ハーブピーリング専門店

実データ（予約クーポンのキーワード別契約率）でも、悩み訴求ワード（いちご鼻・ニキビ・毛穴・黒ずみ・水光肌）が高契約率。

## HPB原稿・文章改善の型

- **店名**：前後やサブタイトルに「ハーブピーリング専門店」を入れる（SEO最優先）
- **キャッチコピー**：「共感（お悩み）＋信頼度の数値化」。例「【繰り返すニキビに】口コミ★4.9のハーブピーリング専門店…」
- **紹介文**：リピート率・満足度・成分/マシンのこだわり・他社との違いを、不自然にならない範囲で盛り込み全体ワード数を底上げ
- **クーポン名の型**：共感（悩み）＋手法（韓国式ハーブピーリング）＋信頼（口コミ★4.9等）

## 課題の原因分解（提案時の指針）

- 新規が少ない → SEO弱い / クーポン弱い / 画像弱い / 価格弱い / ACR低い / 導線弱い
- 契約率が低い → カウンセリング不足 / ヒアリング不足 / クロージング不足 / プラン提案不足
- 稼働率が低い → メニュー設計 / 予約導線 / シフト / 回転率
